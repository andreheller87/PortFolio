# Portfólio — André Heller

Versão moderna e responsiva do portfólio profissional.

## Destaques
- Tema claro / dark com persistência no navegador.
- Layout responsivo para desktop, tablet e celular.
- Navegação fixa com efeito glassmorphism.
- Hero moderno com apresentação profissional.
- Seções de Sobre, Stack, Projetos, Jornada e Contato.
- Cards de projetos com imagens e vídeos.
- Animações suaves ao rolar a página.
- Barra de progresso de leitura.
- Links para GitHub, LinkedIn, WhatsApp e currículo.

## Estrutura

```text
PortFolio/
├── index.html
├── Style.css
├── script.js
├── Curriculo.pdf
├── github.png
├── linkedin.png
├── icons8-whatsapp-480.png
└── image/
```

## Publicar no GitHub Pages

```bash
git add .
git commit -m "Atualiza portfólio"
git push origin main
```

Depois, no GitHub:
**Settings → Pages → Deploy from a branch → main → / (root)**.
